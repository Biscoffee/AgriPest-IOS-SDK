# AgriPest iOS SDK (Objective-C)

这是 AgriPest 系统的官方 iOS (Objective-C) 客户端 SDK。

## 当前版本: 1.0.9

## 快速开始

### 1. 添加依赖 (CocoaPods)
在您的 `Podfile` 中添加：
```ruby
pod 'AgriPestClient', :git => 'git@github.com:lukecc00/AgriPest-IOS-SDK.git', :tag => 'v1.0.9'
```

### 2. 使用
```objc
#import <AgriPestClient/AGApiService.h>
// 开始调用接口...
```
